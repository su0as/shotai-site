# AI Search Optimization Checklist

Based on Google's AI optimization guidance, Shot AI pages should keep these fundamentals in place before publishing.

## Required Signals

- Serve helpful, original content that answers a real player problem before mentioning Shot AI.
- Keep every public page crawlable with a clean canonical URL and no conflicting `noindex` rule.
- Use descriptive titles, meta descriptions, headings, and internal links that match the page topic.
- Add valid `Article` schema to every blog post, including `headline`, `description`, `datePublished`, `dateModified`, `author`, `publisher`, `mainEntityOfPage`, and `image`.
- Add `BreadcrumbList` schema to every blog post so Google can understand the page location.
- Add `ItemList` schema to the blog hub so the article collection is explicit.
- Keep the sitemap updated with clean URLs, not `.html` file paths.
- Use descriptive image alt text and add image loading hints for page experience.
- Make app CTAs useful and contextual, not a replacement for the answer.

## Content Quality Rules

- Start with the user's actual problem in plain language.
- Give practical steps, examples, and tradeoffs.
- Avoid generic filler, unsupported claims, and keyword stuffing.
- Link to related Shot AI guides when they help the reader continue the same learning path.
- Use Shot AI as the feedback loop after the reader understands the practice problem.
